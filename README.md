# BookEase – Doctor Appointment & Management System

BookEase is a full-stack healthcare appointment platform where patients can book appointments, make payments, doctors can manage schedules, and admins can manage the entire system.

## 🔥 Features

- Patient appointment booking & cancellation
- Online payment integration
- Admin dashboard for doctor & availability management
- Secure authentication & role-based access
- REST API architecture
- Deployed backend & frontends

## 🛠 Tech Stack

- Frontend: React, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Payments: Razorpay
- Deployment: Render

## 🌐 Live Links

- Patient App: https://bookease-4qvi.onrender.com/
- Admin Panel: https://bookease-admin.onrender.com/

## ⚠️ Security

Admin credentials are not shared publicly for security reasons. Demo access can be provided on request.
